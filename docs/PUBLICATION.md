# Source publication

This repository publishes the QEdge source, tests, authored fixtures, documentation and retained release evidence. It was copied from the local validated CPU portfolio on 9 November 2026.

Third-party model weights, ABO catalog records/images, generated indexes, virtual environments and build outputs are excluded. The authored fixtures under package source directories are included. Follow the documented acquisition steps for optional model/catalog experiments. Physical Qualcomm hardware execution remains unverified.

Retained historical hashes identify original local artifacts; an excluded acquired asset must be obtained separately before reproducing an asset-dependent check. The offline packaged fixture demo requires no downloaded model or catalog.

The machine-path check applies to active code and documentation. Immutable audit material under docs/research-review/evidence retains its historical paths and is excluded from that portability check.

Default retrieval tests run on authored fixtures. Catalog/index/annotation-dependent tests are explicit skips unless QEDGE_RUN_CATALOG_INTEGRATION=1 is set after acquiring those assets. NumPy is a development dependency for retrieval tests; the installed offline fixture CLI does not acquire it.
